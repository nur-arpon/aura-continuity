# Aura icon (SpaceZ)
`aura-icon.svg` is the source (108x108 adaptive-icon grid; content inside the central 66 circle so it survives round/squircle masks).
A soft presence field around a dot: your devices sensing you nearby. Palette: navy #070F1C..#16305A, blue #5AA2FF, sky #8EC5FF.
Android vector versions: `unlock-watch/wear/src/main/res/drawable/ic_aura_bg.xml` + `ic_aura_fg.xml` (adaptive icon), `aura-glyph-24.xml` (monochrome 24dp glyph for notifications / tiles).
