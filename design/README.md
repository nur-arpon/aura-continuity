# Continuity design system

One look for every Continuity app (AutoLock, Handoff, and the unlock app when it
gets a window): deep navy, mid-blue surfaces, one bright blue for the action,
teal for "all good", amber for "needs you". Its own palette, not Spike's.

## Files

| File | What it is |
|---|---|
| `tokens.css` | Colours (dark + light), type ramp, spacing, radii, sizes, motion. The only place a value lives. |
| `components.css` | Window frame, status card, grouped rows, switch, checkbox, segmented control, field, select, slider, buttons, chips, empty states, focus, entrance motion. |
| `ui-icons.js` | Inline SVG sprite for in-window icons (20 px grid, 1.5 px stroke). |
| `icons/*.svg` | App icon and tray icon sources (generated by `tools/make_icons.py`). |
| `tools/make_icons.py` | Writes the SVG sources and renders every PNG/ICO into each app's `src-tauri/icons`. |
| `sync.ps1` | Copies the three shared files and the app mark into each app's `ui/`. |
| `previews/` | Icon contact sheets (1x, and 4x nearest-neighbour for the small sizes). |
| `screenshots/` | Real settings windows, taken from the running exes. |

Tauri serves only an app's own `ui/` folder, so each app carries a copy of the
shared files. **Edit here, run `sync.ps1`, rebuild.** The copies say so in
their first line.

```
python  D:\Claude-Projects\Continuity\design\tools\make_icons.py   # icons
powershell -File D:\Claude-Projects\Continuity\design\sync.ps1     # css/js into ui\
```

Rules: one accent (bright blue) and it means state or action, never
decoration. Teal and amber are semantic only and always come with text or an
icon (chips have a dot *and* a word). Dark is the default (the family is
navy-first); light follows `prefers-color-scheme`; `data-theme` on `<html>`
can force either. Forced-colours (Windows high contrast) hands borders and
focus to the system.

## Type, space, shape

- Segoe UI Variable (Text for 12-18 px, Display for 20 px+), the Fluent ramp:
  12/16 caption, 14/20 body, 16/22 status title, 20/28 window title. Regular
  and Semibold only.
- 4 px base: 4 8 12 16 20 24 32 40 48. Window edge 24, card padding 16,
  between sections 24, label-to-control 16, section title to its card 8.
- Controls 32 px tall, rows 48 px, nothing clickable under 32 px.
- Radii scale with surface: 4 controls, 8 cards, 12 the one status card,
  pills for chips.
- Cards separate by tint plus a hairline, no drop shadows inside a window.

## Motion

| Token | Value | Use |
|---|---|---|
| `--dur-instant` | 100 ms | hover, focus, press |
| `--dur-fast` | 167 ms | toggles, checkbox, chip colour (Fluent "fast") |
| `--dur-normal` | 250 ms | status change cross-fade |
| `--dur-slow` | 333 ms | window content entrance |
| `--spring-snappy` | k 300, c 30, m 1, sampled as `linear()` over 480 ms | switch thumb, check mark, slider thumb |
| `--ease-fluent` | `cubic-bezier(0.1, 0.9, 0.2, 1)` | entrance |
| `--stagger` | 30 ms | status card, then each section |

Only `transform` and `opacity` move; colour changes are limited to small
controls. Status numbers that tick every second do not animate; only a new
*kind* of status cross-fades. Reduced motion keeps the fades and drops all
travel and springs.

## Icons

Every Continuity icon is a navy squircle (`#1F4C8F` to `#0B1B38`) with a
bright-blue orbit and a dot: "your other device, nearby". The glyph in the
middle names the app (padlock = AutoLock, phone with an arriving arrow =
Handoff). 16 px and 24 px frames are drawn on their own pixel grid (the orbit
is dropped at 16 px; the dot stays). ICO frames: 16, 20, 24, 32, 40, 48, 64,
256.

Tray icons (48 px PNG drawn on a 24 px grid, exact 2:1 at this laptop's 150 %):

| App | State | Look |
|---|---|---|
| AutoLock | dry run | navy tile, hollow padlock |
| AutoLock | live | bright-blue tile, solid padlock |
| AutoLock | paused / Bluetooth off | slate tile, two pause bars |
| Handoff | idle | navy tile, phone, light-blue arrow |
| Handoff | sending | bright-blue tile, phone, white arrow |
| Handoff | queued | navy tile, phone, amber clock badge |

State is carried by shape as well as colour, so it survives colour-blindness
and a monochrome taskbar screenshot.

## Not done here (needs a Rust change, out of scope for the design pass)

- **Mica**: the settings windows are built in Rust (`WebviewWindowBuilder`).
  Mica needs `.transparent(true)` plus `.effects(EffectsBuilder::new().effect(Effect::Mica).build())`
  and `--bg: transparent` on `body`. The tokens are ready for it.
- **Handoff tray states**: `tray-idle/sending/queued.png` exist; `app.rs` still
  loads only `tray.png` (now the idle art). Wiring needs a `set_icon` in
  `refresh_tray` (queued when `queue.len() > 0`) and around the send.
- **Caption bar colour** (DWM `DWMWA_CAPTION_COLOR` to `--bg`) so the title bar
  is navy, not grey.
- **Tray menu wording** (strings live in Rust); suggestions:
  AutoLock `"LIVE - Nearby: X"` to `"Live · X is nearby"`; `"Live mode (really lock)"`
  to `"Live mode (really locks)"`; `"Settings..."` to `"Settings…"`; `"Quit"` to
  `"Exit AutoLock"` (matches Handoff's `"Exit Handoff"`). Handoff's menu is
  already in this voice.
- **Esc to close** in AutoLock: its capability file lacks `core:window:allow-close`.
